## 最新约定（2026-09-10）

用户确认三平台内容已准备好，将目标从三站一键公开发表调整为：每期一个内容项目，生成三平台版本，准备可审核草稿，最终发表由用户手动触发。网站采用本地草稿预览；公众号为官方 API 草稿；小红书为当前创作浏览器中的本地草稿。不新增 CMS、网站后台或管理界面。

这次整理不自动撤下已经获准公开的网站首篇，不再次部署，不发表公众号或小红书，不 push，不修改跨会话记忆。

## 验收标准

1. 每期原始素材、唯一工作稿、试验和平台交付物集中在 content-projects/<id>/，原始 Markdown 字节不变。
2. prepare 从新的工作稿位置生成本地包，读取回执、增补资料不导致渲染版本变化；平台人工编辑稿不被覆盖。
3. 网站草稿只能通过本地预览阅读，普通构建只包含 published 内容，私人资料不进入 Git 或公开产物。
4. 公众号已有稿可通过统一命令回读，更新须绑定最近的 bodyHash；保存与发表明确分开。
5. 文档和 skill 只描述已实现能力，不把本地生成称为三站云端存稿，不把尚未实测的小红书公开发布当作已验证。
6. 清理旧 LDP 流程及调试材料，保留最终稿、必要回执和恢复入口。工具禁止删除时采用可恢复归档，如实记录而不绕过。
